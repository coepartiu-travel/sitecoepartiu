# COÉ, PARTIU? — Travel & Experiences

## Sobre o Projeto
Site MVP da COÉ, PARTIU? Travel & Experiences, uma agência de viagens digital focada em experiências personalizadas, Atacama & Chile, Lua de Mel, Escolas e Grupos.

## Tecnologias
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL)
- Vercel (Deploy)
- React Hook Form + Zod
